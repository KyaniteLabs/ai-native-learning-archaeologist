# Dev Learning Archaeologist

Forensic git-history learning diagnostic for AI-assisted developers. Turns commit history into evidence-backed study plans and HTML reports (ICM-style specialist pack).

**Who it is for:** developers who want a learning diagnostic from *this* repo’s history, not a generic quiz.

## Quick start

```bash
git clone https://github.com/simongonzalezdc/dev-learning-archaeologist.git
cp -r dev-learning-archaeologist /path/to/your-project/
cd /path/to/your-project
# open Claude Code (or your agent) and run the in-pack instructions
```
